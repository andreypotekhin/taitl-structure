## Context and Orientation

The catalog is `docs/reference/pyspark-transformation-coverage.json`, guarded by
`tests/specifications/compatibility/test_pyspark_transformation_coverage.py`. Classic live concepts and integration
tests use the Compose targets `pyspark35` and `pyspark40`. V4 streaming evidence is in
`tests/integration/pyspark/v4/test_streaming_migration.py`. Core retains no streaming lifecycle ownership.

## Plan of Work

Run the catalog and generated-artifact guards before the full build. Run each classic Compose lane after the default
build. Treat a failure as a release blocker unless the public contract is explicitly reduced and recorded in the gaps
document. Do not count skipped live tests as release evidence. Update the sprint and this plan with the commands and
totals, then move this plan to `docs/dev/planning/done/` only when every acceptance criterion is met.

## Validation and Acceptance

Run `make build`, `make integration BACKEND=pyspark35`, and `make integration BACKEND=pyspark40`. The default build
must pass; each classic Compose lane must execute the V4 streaming plan-construction coverage. The catalog guard must
find exactly one actionable classification per local inventory API.

## Outcomes & Retrospective

`make build` passed with 1081 tests passing and 22 Spark-dependent tests skipped in the local PySpark-free environment.
The catalog/golden guard passed with 7 tests passing and one expected local live-test skip. Both `pyspark35` and
`pyspark40` Compose lanes completed successfully, each collecting 22 integration tests including the V4 streaming
plan-construction scenario. The public V4 guide, coverage reference, streaming reference, and whitepaper now describe
the delivered caller-owned streaming shapes and the still-deferred parser, generator, set-operation, and relation-order
contracts.

Performance benchmarks remain deferred: `CompilerPerformanceTargets.md` explicitly makes them non-release-blocking
until benchmark infrastructure exists. This hardening pass did not find a release-blocking regression.
