# Deferred: v3 Streaming Orchestration

This former v3 ExecPlan is retained as historical context only.

## Decision

On 2026-07-12, `D07122601.Streaming-lifecycle-remains-caller-owned.md` deferred this scope beyond v3. Structure will
not generate `readStream`/`writeStream`, configure triggers or checkpoints, apply output modes, or start and manage
Spark queries. Those concerns are caller-owned orchestration rather than Structure transformations.

## Replacement

Sprint 16 uses `docs/dev/planning/P07122601.Streams-example-and-caller-owned-streaming.plan.md` to harden admitted
transformations and prove them with a caller-owned file-stream example.

## Reconsideration Bar

A future proposal may reopen lifecycle ownership only with a separate product decision, explicit operational semantics,
failure/recovery policy, security review, live integration evidence, and end-user documentation that makes ownership
unambiguous.
