### D06172605 Use Schema as the Base Class Name

Use `Schema` as the canonical base class name instead of `Structure`.

`Schema` makes the base class's role explicit while preserving Structure as the project and library name. The class
represents a declared row contract used for Spark `StructType` generation, validation, traceability, and transform type
flow. The API uses
examples such as `from structure import Schema` and `class Customer(Schema)`.

The current spelling already keeps nested schema use natural:

```python
class Address(Schema):
    city = field(String(), nullable=True)


class Customer(Schema):
    address = field(Struct(Address), nullable=True)
```

The public API and documentation use `Schema` consistently.
