# Decision: V9 Streaming Is Support-First

## Status

Accepted on 2026-07-30.

## Context

V9 expands PySpark streaming coverage beyond the original compatibility slice. The public API catalog now tracks
Structure-supported transformations, caller-owned lifecycle and adoption APIs, design-gated rows, streaming-ineligible
rows, and out-of-scope targets. Several extended rows require state, target-profile, side-effect, or lifecycle design
before Structure can claim support.

The project should avoid two weak outcomes: claiming support without evidence, and leaving plausible high-adoption
streaming APIs parked as generic future work. Streaming adoption is a core v9 goal, so design gates should be active
proving lanes.

## Decision

V9 takes a support-first stance for the extended PySpark streaming API surface.

For every extended streaming row, the implementation path first attempts one of these outcomes:

- a typed Structure-supported transform contract with compiler-visible state, output-mode, diagnostics, generated-source,
  online execution, and live target evidence;
- executable caller-owned guidance when the API is operational lifecycle or side-effect code that must remain outside
  generated transforms.

Rows move to `streaming-ineligible` only when Spark semantics, state safety, or lifecycle ownership make support unsafe
and the decision is backed by tests or live evidence. Rows remain `design-gated` only when the missing contract is named
and scheduled as design work.

Target-gated streaming support must be profile-aware. A PySpark 4-only streaming claim needs positive evidence on the
supported profile and rejection evidence on older profiles.

## Consequences

The first implementation slice closes evidence gaps for already admitted Variant streaming helpers. Chained
`window_time(...)` aggregation, finite selected-row helpers, finite analytic-window alternatives, caller-owned side-effect
guidance, and a typed arbitrary-state model follow as implementation tracks rather than passive backlog.

The existing streaming lifecycle decision remains intact: Structure transforms DataFrames and does not start or operate
streaming queries from generated transform modules.
