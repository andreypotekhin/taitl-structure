# D07202603 Package Source-Root Discovery

Structure supports both plain directories and Python packages as configured
source roots. A plain directory keeps the existing behavior: module names are
relative to that directory, and the directory itself is added to `sys.path`.

When a source root contains `__init__.py`, discovery treats it as a package.
It adds the nearest non-package parent to `sys.path` and prefixes every
discovered module with the package path. Nested package roots walk upward
through contiguous `__init__.py` parents.

For example, `source_roots = ["examples/texts"]` discovers
`examples.texts.transforms.search.ScoreCorpus`, rather than
`texts.transforms.search.ScoreCorpus`. This preserves normal absolute imports
and prevents child packages such as `examples.math` from colliding with Python's
standard-library `math` module.

`__init__.py` remains a package marker rather than a discovery registry:
Structure does not require re-exporting transforms from either a package or
subpackage initializer.
