# D07122601 Streaming Lifecycle Remains Caller-Owned

Structure transforms DataFrames; it does not operate streaming jobs. Spark source selection, sink selection, output
mode application, triggers, checkpoints, query names, startup, shutdown, deployment, and recovery remain caller-owned
in every release.

Watermarks, stateful transformation shapes, and output-mode requirements remain compiler-visible where Structure can
define their data semantics. Explain output may state the mode Spark requires, but Structure never applies it through
`writeStream`.

This decision supersedes the planned v3 streaming-lifecycle ownership described by Sprint 16 and its original ExecPlan.
The postponed plan remains historical context only. Future work may admit additional streaming transformations only
when their state and late-data behavior are explicit, diagnosable, and independently testable.
