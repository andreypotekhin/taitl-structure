### I09202601 Generated Schema Constants Missing From Programmatic Source

Status: resolved
Scope: generated PySpark source assembled through programmatic `generate(...)`
Versions: Structure 4.0.0, Python 3.11, PySpark 4.0.0

Reproduction:

Run [generated_schemas.py](../../../res/testing/support/generated_schemas.py) in the Spark integration image. The
reproduction deliberately supplies no source schema roots to the generated-source configuration.

Observed output before the fix:

```text
NameError: name 'ROW_SCHEMA' is not defined
```

The generated transform referred to its input schema constant without emitting the schema module that defines it.

Expected behavior:

Programmatic generation discovers every schema reachable from the compiler plan, including inherited and nested
schemas, and emits each required schema module before generated transforms import it.

Resolution:

- `CompletePySparkSchemaModules` completes the caller's schema-module map from the compiled plan and traverses
  inherited, struct, array, and map schema dependencies.
- `tests/specifications/pyspark-code-generation/test_missing_schema_modules.py` verifies deterministic generated
  output with an empty source-module map.
- The original failing output is preserved in
  [generated_schemas.before.txt](../../../res/testing/support/generated_schemas.before.txt).
