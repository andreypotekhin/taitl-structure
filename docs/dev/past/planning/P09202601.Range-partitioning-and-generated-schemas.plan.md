## Context and Orientation


`Transform.generate` in `src/structure/core/dsl/model/transforms/Transform.py` supplies discovered schema modules
to the PySpark generator. `StructureConfig.create()` permits empty source roots; compilation still knows its
schema classes, but `RenderPySparkProject` currently trusts discovery alone. Generated transforms then reference
constants such as `ROW_SCHEMA` without defining or importing them. A schema dependency is a schema referenced by
an input, output, step, validation, nested field, or UDF type in the compiled work.

Relation helpers live in `src/structure/plugin/pyspark/dsl/relation_sets.py`. `OperationPlan` records typed operations,
`MapPySparkStep` lowers them to execution recipes, `RunOnlinePySparkTransform` runs them, and `RenderPySparkStep`
emits PySpark. Expression scope checks, inherited-step rewriting, streaming classification, capability metadata,
explain, and traceability must recognize a new operation. Distribution by ranges preserves rows and schemas but
does not establish the ordering required by `limit` or `offset`.
