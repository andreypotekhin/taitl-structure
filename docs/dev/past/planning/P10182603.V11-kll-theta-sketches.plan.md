## Purpose / Big Picture

Users will be able to build approximate numeric distributions with KLL sketches and approximate distinct-value sets with Theta sketches, then query and combine them through typed Structure expressions. Sketches remain opaque Spark Binary values while Structure retains their family and the KLL numeric domain. Schema metadata will preserve logical identity across generated transforms and supported storage boundaries for KLL, Theta, HLL, and Bitmap.

Completion requires matching native, online, and generated behavior. Ordinary and Spark Connect 4.1 batch claims and ordinary 4.1 streaming/restart claims require positive evidence. Spark Connect remains outside the project's Structured Streaming support boundary. The default profile is `>=3.5,<4.2`; KLL/Theta remain gated to exact `>=4.1,<4.2` targets.

## Surprises & Discoveries

Disposable ordinary Spark 4.1.0 probes found non-null empty KLL sketches, count zero, and native KLL_SKETCH_INVALID_INPUT failures for empty rank/quantile queries. Null sketch inputs propagated null. KLL rank and quantile accepted arrays; null array elements passed to quantile produced native zero-rank behavior. KLL ignored NaN inputs, counted infinities, and pairwise merged mixed k values in all three numeric domains.

Theta estimates returned Long. Empty/all-null sketches estimated zero. Theta accepted Integer/Long/Float/Double/String/Binary and integral arrays; array elements form one value, so `[1, 2]` and `[2, 1]` differed. Empty strings, bytes, and arrays were ignored.

Spark 4.1.0 provides pairwise KLL merge but no KLL merge aggregate in either the Python API or SQL registry. A field metadata tag survived aliasing and Parquet; casts and computed expressions dropped it. Parquet widened field nullability. Reattach metadata to produced sketch outputs and preserve Spark’s storage-read nullability.

## Decision Log

- Decision: Use generic KLL helper names, dispatching to native bigint/float/double functions from an explicit KLL domain. Map Integer/Long inputs to Long; require explicit casts for Decimal. Rationale: the logical type records the native dispatch domain.
- Decision: Use one Theta type with no source domain. Keep KLL `k` and Theta `lg_nom_entries` in operation configuration, outside type identity. Rationale: precision describes an aggregate operation and mixed precision is natively supported.
- Decision: Export six KLL helpers and seven Theta helpers, with no public suffix variants and no KLL merge aggregate. Rationale: match the pinned 4.1.0 native surface.
- Decision: Persist metadata for KLL, Theta, HLL, and Bitmap. Descriptor kind matches public factories; version describes Structure’s descriptor format. Do not persist profile or KLL/Theta operation precision.
- Decision: Remove profile from identity; reject old `profile=` factory use with migration guidance to `plugin.pyspark.profile`.
- Decision: Missing metadata may be supplied by an explicit schema. Malformed, unsupported-version, or conflicting metadata always fails. Untagged Binary remains Binary absent an explicit declaration.
- Decision: Preserve native empty KLL errors and native input behavior. Do not add safe variants or decode payloads to validate metadata.
- Decision: Admit KLL/Theta batch for ordinary and Connect 4.1 after independent parity. Admit streaming/restart only for ordinary PySpark 4.1 after positive evidence; Spark Connect remains outside the existing Structured Streaming support boundary. Restart claims apply only to the same query and sketch configuration.

## Context and Orientation

The symbolic DSL records typed expressions; the PySpark compiler recipes feed both online execution and generated source. Logical sketch types are in `src/structure/plugin/pyspark/dsl/types/SketchType.py`; factories are in `dsl/field.py` and `dsl/types/__init__.py`. Expression and aggregate helpers are in `dsl/expressions.py` and `dsl/operations_api.py`. The evaluator, renderers, and schema materializer must agree; do not add a separate execution path.

Schema handling lives under `src/structure/plugin/pyspark/schema/`, online boundary checks in `execution/logic/ValidatePySparkFrame.py`, generated runtime checks in `resources/runtime.py.template`, and admission rules in `capabilities/model/PySparkCapabilities.py`. Metadata key `structure.logical_type` carries a versioned logical descriptor while Spark stores the value as Binary. Nested struct fields carry their own descriptors; array elements and map keys/values without StructFields are represented recursively by the enclosing field descriptor. Preserve unrelated metadata and reject conflicts. No serialized-payload portability is promised.

Streaming classification uses existing aggregate and watermark/state rules. Keep state processors, foreachBatch interfaces, query ownership, checkpoint paths, and sinks caller-owned. Preserve the integration launcher’s provider phases, dependency caches, and service cleanup.

## Interfaces and Dependencies

Public field/type declarations are `kll_sketch(domain, **field_options)`, `theta_sketch(**field_options)`, `hll_sketch(*, lg_config_k=12, **field_options)`, and `bitmap(**field_options)`. KLL domain is one of `long()`, `float()`, or `double()`. HLL retains `lg_config_k` identity; Bitmap and Theta carry only kind.

Public KLL operations are `kll_sketch_agg(value, *, k=200, where=None)`, `kll_sketch_get_n(sketch)`, `kll_sketch_get_quantile(sketch, rank)`, `kll_sketch_get_rank(sketch, quantile)`, `kll_sketch_merge(left, right)`, and `kll_sketch_to_string(sketch)`. Validate literal integer k in 8–65535, excluding bool. Query functions preserve native scalar/array results; count is Long, rank is Double, and quantile is the sketch domain.

Public Theta operations are `theta_sketch_agg(value, *, lg_nom_entries=12, where=None)`, `theta_union(left, right, *, lg_nom_entries=12)`, `theta_union_agg(value, *, lg_nom_entries=12, where=None)`, `theta_intersection(left, right)`, `theta_intersection_agg(value, *, where=None)`, `theta_difference(left, right)`, and `theta_sketch_estimate(value)`. Validate literal integer precision 4–26, excluding bool. Estimate is Long; other operations return Theta. Validate native nullability through live probes before fixing expression contracts.

KLL/Theta require exact `>=4.1,<4.2` ordinary or Connect capability admission. Existing HLL/Bitmap capability and precision behavior stay intact. Use only pinned PySpark/Spark 4.1.0 dependencies; add no runtime package.
