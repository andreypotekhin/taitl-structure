### D07132603 Mirrored Generated Method Layout

Generated code keeps its compact `run(*, inputs)` layout by default. Projects may opt into
`generated_code_options = ["mirror_methods"]`, which places original input DataFrames in the generated constructor and
renders source-named schema steps as zero-argument state transitions over instance-held DataFrames.

Each mirrored generated object represents one input batch and is constructed for that batch. This avoids mutable input
rebinding and makes concurrent batch execution safe when callers use separate instances. Expression specials are inline
by default; `embed_exprs`, `embed_hooks`, and `embed_udfs` are independent choices that alter generated source identity,
not the compiled execution semantics.
