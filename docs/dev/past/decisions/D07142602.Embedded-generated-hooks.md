### D07142602 Embedded Generated Hooks

`generated_code_options = ["embed_hooks"]` creates a source-transform-free generated PySpark module for raw hooks.
The generated method is an AST-normalized copy of the declaring hook body, without its `@raw` decorator, while the
compiled hook recipe remains the authority for placement, validation, and target metadata.

Embedding is deliberately conservative. A copied hook may use parameters, local values and imports, Python builtins,
and `self.spark` or `self.ctx`; it may not depend on source-module globals, closures, `super()`, or source instance
state. This keeps generated artifacts reviewable and independently importable without pretending to analyze opaque
PySpark code. `GEN-E0903` explains unsupported cases.

Python UDFs remain a separate source-packaging boundary. `embed_hooks` rejects a UDF-bearing plan unless the independent
`embed_udfs` option is present. Inherited hook recipes dispatch through the declaring generated owner class, preventing
a same-named child method from changing a selected parent boundary.
