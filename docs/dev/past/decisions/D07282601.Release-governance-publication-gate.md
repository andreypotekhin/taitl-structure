### D07282601 Release Governance Publication Gate

Public v6 publication is blocked on a project-owner governance decision, not on compiler implementation.

The project owner must choose and record:

- license model: OSI-open-source, source-available, dual license, or another explicit policy;
- distribution name and package metadata;
- contribution guide requirements;
- security contact and vulnerability reporting path;
- release process, support window, and compatibility statement;
- code of conduct or a written decision that the project will not publish one for the first release.

Until that decision is made, implementation may continue, internal packages may be built, and release evidence may be
collected. External publication, public package-index release, and open-source claims must not proceed.

The publication checklist is complete only when `Readme.md`, `License.md`, `pyproject.toml`, contribution/security
documents, generated examples, and compatibility docs use the same naming and licensing language.
