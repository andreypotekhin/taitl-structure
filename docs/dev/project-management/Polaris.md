# Polaris

# Batch processing
1. Maximum convenience for end-user who migrates batch data transformation pipelines flom plain PySpark to Structure.
End-user should be able to:
- Express most PySpark data transformation scenarios in Structure-based code.
- Be able to use escape hatches for few scenarios that can't be expressed in Structure-based code.

# Streaming
We want Structure streaming capability grow in two ways:
1. Maximum convenience for end-user who switches from batch to streaming dataframes.
2. Maximum convenience for end-user who migrates streaming pipelines flom plain PySpark to Structure.
