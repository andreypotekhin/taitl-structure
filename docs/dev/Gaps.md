# Parity Pointer

The maintained PySpark parity and boundary register is
[Parity](Parity.md). Cross-family API design gates are in
[API Catalog Gates](gated/ApiCatalog.gates.md), and function-specific gates are in
[Function Gates](gated/Functions.gates.md). Streaming gates are in
[Streaming Gates](gated/Streaming.gates.md).

This compatibility pointer remains for existing links. New parity and boundary updates belong in `Parity.md`; design
gates and deferred direction belong under `gated/` and `deferred/`.
